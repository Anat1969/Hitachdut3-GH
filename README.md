# יומן ביקורי אתר

יומן לאדריכלית מפקחת. היא רושמת ממצאים מכל ביקור באתר בנייה, ורואה אותם מאורגנים לפי פרויקט.

- הביקורים בכל פרויקט ממוספרים לפי סדר התאריכים.
- לכל פרויקט יש סטטוס: בתהליך או הסתיים.
- לכל ממצא אפשר לצרף תמונה, מהמצלמה או מהגלריה.
- הכול נשמר בטלפון עצמו, בלי חשבון ובלי שרת.

קובץ אחד: `index.html`. ההחלטות וההיסטוריה נמצאות ב-`CLAUDE.md`.
